# 📌 Katalog Produk Responsif

##  Deskripsi Proyek
Proyek ini merupakan tugas rutin 3 mata kuliah Pemrograman Web, yaitu membuat halaman katalog produk yang responsif menggunakan Bootstrap atau Tailwind CSS. Website dirancang agar dapat menyesuaikan tampilan pada berbagai ukuran layar, mulai dari smartphone, tablet, hingga desktop.

## Tujuan
- Membuat katalog produk yang responsif.
- Menerapkan desain mobile-first.
- Memahami penggunaan grid dan breakpoint.
- Menampilkan informasi produk dengan rapi dan menarik.

##  Teknologi yang Digunakan
- HTML5
- CSS3
- Bootstrap atau Tailwind CSS
- JavaScript (jika diperlukan)

## Fitur Utama
1. **Responsive Navbar** — navigasi menyesuaikan ukuran layar, termasuk hamburger menu pada perangkat mobile.
2. **Responsive Product Grid** — susunan produk berubah sesuai ukuran layar:
   - Mobile: 1–2 kolom
   - Tablet: 2–3 kolom
   - Desktop: 3–4 kolom
3. **Product Card** — menampilkan gambar, nama produk, deskripsi singkat, harga, dan tombol aksi.
4. **Responsive Images** — gambar menyesuaikan ukuran kontainer.
5. **Responsive Typography** — ukuran teks menyesuaikan layar menggunakan `clamp()`.
6. **Footer** — menampilkan informasi tambahan dan hak cipta.

## Breakpoint Responsif
- Mobile: kurang dari 576px
- Tablet: 576px–991px
- Desktop: 992px ke atas

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka folder proyek di Visual Studio Code.
3. Jalankan `index.html` menggunakan browser atau ekstensi Live Server.
4. Ubah ukuran layar browser untuk menguji tampilan responsif.
